# 学习家园 · 数学手记设计系统

对应 Issue23，沿用PR22和同一工作副本；第一课教学、图形量纲与六步顺序保留，重做外层信息结构和全部页面视觉。本轮只在全部实现/自测/修复/同一NAS验收后集中提交审计，不按模块暂停。

## 设计方向与自评修订

对象是三年级孩子和陪伴的家长。主任务是找到正在学的知识、看懂条件、操作模型、独立解释和自查。用“数学手记”的纸张、教材书脊、真实几何线条组织界面；不用虚拟积分、假进度或大段营销文案。

初稿若只是奶油白加圆角卡片，会继续复现上一版的弱点。修订为有主次的编辑式布局：书本学习是清楚的主入口；探索是有内容图示的次入口；工具与复习用简洁索引。真实数学模型承担视觉主角，边框只表达组/输入/选中状态；不用一律同尺寸的大卡片或无意义渐变。这是上一轮由Codex自行选择的视觉方向，并非用户指定；用户已明确否定这一版效果。

桌面1440/1280：安静的学科侧栏+主内容；平板768：紧凑页头和可展开导航；手机390/360：单列阅读、明确的目录/步骤入口，菜单可键盘操作。课堂中步骤和主要任务优先，来源/先修/家长说明渐进披露。按钮有focus/hover/pressed/disabled；reduced-motion取消非必要运动。

## 信息层级

1. 学习家园：按课本学习为主；专题探索、数学侦探、思维训练、复习、方法共六条路径。首页不堆几十个指标。
2. 学习目录：册→单元→知识点→B/E/O/R；高年级为年级→实际主题，不伪造教材册次。
3. 课堂/任务：条件图→行动→解释→自查证据→反馈；提示和标准解分级揭示，首答独立性有明确边界。

共同壳和组件可供后续英语使用；当前英语与积分/蛋仔不开发。

## R3 · 用户否定后的视觉整改（2026-10-30）

用户认为上一版比原数学站差，当前视觉不能标记为用户认可。上一版暖纸、宋体大标题、过多空白和索引式入口偏成人文档阅读，不符合本产品的儿童学习任务。保留前版截图与结论供追溯，不用自动化通过来抵消用户的实际反馈。

本次以原数学站 `8292de8:src/styles.css` 的深青绿侧栏、薄荷色画布、明亮黄色操作和白色学习区为直接参考。两种方向比较：继续编辑式手记会延续已被否定的严肃感；恢复原站的数学实验室语言更接近用户认可的基础。因此选后者，保留真实课程分册/单元层级，去除巨大宣传标题，增加可识别的教材图示和清楚的学习动作。不会复制原站的私人进度、积分或宠物状态。
