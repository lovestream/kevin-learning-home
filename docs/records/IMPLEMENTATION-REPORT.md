## 延续已有实现

- 独立私有 SQLite，严格 schema、WAL/FULL、单 writer 内核 flock；原基础测试仓库的 synthetic 闸门没有移除。
- 不可变来源字节快照 → 完整科目 JSON → 可重建索引/事实事件；未知字段、大整数文本、数组顺序、空值和旧钱包原文保留。
- 来源导入按学习者/科目/来源哈希去重，事务、修订号和回执一起保存。数学适配复用原判分/首答/三项自查/家长复核，不凭操作完成发奖励。
