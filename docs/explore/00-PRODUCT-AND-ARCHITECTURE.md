## 2026-11-03 用户修订：孩子直接学习，仅家长查看需登录

这是用户在当前对话中的明确决定，优先于任务书中泛化的“孩子登录/再次登录”表述。

- Kevin 打开学习家园即可学数学、英语、探索。不注册儿童账号，不输入儿童密码/PIN，不切换多套账号。
- 家长查看学习情况、反馈及管理备份时，才进入同一家园的家长入口，用**一个家长账号、由家长亲自设置的密码**。不再叠加第二套家长 PIN，不把数学/英语/探索各设密码。
- `learnerId` 仍是服务端内部稳定标识，不是让孩子填写的账户。未来私有设备会话由同一记录底座自动选定家庭内的学习者；不会通过 URL/localStorage 的自报 ID 授权。
- 当前版本没有需要登录的真实家长报告；不放无效登录框，也不生成、索要或提交用户密码。现有 `packages/auth` 的安全保护和回归原样保留。
- **免输入密码不等于匿名公开历史。** 正式跨设备个人数据访问由 #24 完成家庭设备授权/可信访问。设备首次接入可以由家长批准一次，孩子日常不重复登录；家长报告的密码会话独立、短期、可退出，不由儿童会话继承。报告不得塞进匿名课堂 DTO。
- 本轮不改 DSM、Docker 权限、Tailscale、域名或证书；现有 LAN HTTP 预览继续使用原地址。未来正式存储的访问实现单独审查，不以自动放宽原生产 HTTPS/CSRF 设置实现“免密码”。

## 教育闭环与信息架构

探索是 `activityModule=explore` 的自主活动，和数学/英语并列，**不是 SubjectModule.listCourses 的第三个学科**。自主问题可以没有课程引用，也可以关联多个科目。

入口：`/explore` → 问题库 `/explore/questions` / 正在探索 `/explore/projects` / 我的创造 `/explore/creations` / 发现档案 `/explore/archive`。保持同一个 DesignShell、同一个 NAS38444 入口、同一菜单。英语与成长未上线，不能伪造已迁入。

核心动作：自己问 → 首猜（允许“我还不知道”）→ 计划 → 观察/资料 → 反证和修订 → 暂时解释/未解疑点 → 可选创造 → 回看。允许跳着做、暂停、失败、重开、无图无作品无结论。每周选一题仅是建议，无期限、排名、扣分或强制配额。

首猜是追加历史中的第一条假设事实，不因新结论被覆盖。观察、资料原意、自己的解释、家长说明和 AI 建议分别标注。想象故事不是现实实验；公开示例不是孩子真实行为。规则教练只问小问题，首猜前不打开更强提示，默认无第三方 AI。

## 视觉设计：把问题放在桌面中央

- 颜色延续数学：深青 `#173d43`、薄荷底 `#edf7f5`、白纸 `#fff`、提示青 `#167d7f`、黄色 `#f6c848`。只用淡紫区分资料/不确定性，不做一套新品牌。
- 字体沿用系统中文无衬线；主问题 30–48px，正文17px，辅助14–15px，触控≥44px。
- 首屏左边一句问题邀请，右边纸盒观察插画（自绘SVG，属于界面插画，不冒充实物证据）；下一行一张可写问题纸。案例按问题行展开，不做四个相同大白框。
- 工作台以一张书写纸为主，旁边是可选离线提示；窄屏提示下移。五个动作页可自由切换，历史以时间线显示。第一猜想固定以黄色侧线区分，证据来源有文字标签而非只靠颜色。
- 第一次设计复核去掉了满屏指标、连续天数、百分比和奖励按钮。第二次复核依据真实截图检查手机标题、操作密度、菜单和正文行宽。实际结果见执行报告；实体 iPad/Safari 不能用模拟视口冒充。

| 能力                  | 匿名HTTP内容体验 | 日常学习设备（未来，孩子无登录） | 家长密码会话（未来）       |

## 内容与儿童安全

不鼓励独自用火、电、药品、锐器或化学物，安全边界先于提示。可以改用纸模型、画图、已有资料观察，必要时请家长陪同。关键词提示只是离线辅助，**不是已完成的危险内容识别器或家庭监护替代品**；正式AI安全仍须 #30 专项验收。系统不编造实验结果、家长/AI参与不能冒充独立完成。公开示例均为人工编写的设计样例，GitHub不存儿童真实作品。
