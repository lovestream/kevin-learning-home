## 原规则与实现

来源仍固定 `word-request@d0b42a8872a7e87433b96770519203630223b6f2` 的 `assets/app.js:5636–5706`，只读Git blob，没有启动旧应用或读旧state。

| 原行为 | 新站行为及边界 |
|---|---|
| 本词库抽5词，45秒拼写 | 准备页主动选择四个已装载词库之一，随机抽5个不同原词ID；不依赖尚未迁入的today.bank。词库不足5词时遵循原slice语义，真实四库均满足5词。 |

| Flash Fox固定节奏 | 保留原计时器实际节奏：第1/5/9/13/17秒各100分，最高500。明确是本机机器人，不伪装真人或实时在线对手。 |
| 逐秒倒数 | 服务端用单调时钟（performance.now）按真实经过时间核对45秒，轮询暂停/浏览器后台节流不会延长比赛；系统日期/墙上时钟回拨不会延长比赛；作答发生日期仍单独记录。到时未确认的答案不记新作答/分数。 |
| 提前完成或时间到结算 | 正确词数×100与机器人分比较；结束时间、结果冻结，之后查看/重试不重新计算。时间到的done不等同5词completed。 |
| 原试玩曾发XP/金币 | 新匿名站不复制该奖励写入。这里只显示比赛分，`rewardEligible=false`，不写旧钱包、统一积分或独立掌握。 |
| 退出、再玩 | 退出本局后不继续显示本局；切路由或卸载会关闭临时会话，过期仍由原RAM清理保护。新局不复用旧局证据。 |

没有复制原微信邀请占位按钮、假二维码或排行榜。比赛中不提供读音、首字母或参考；结束后才展示5词答案及“首答正确／已订正／未作答”。慢练可随时退回书架。比赛速度和输赢不能推断长期掌握。

## 状态与传输不变量

- 原正常练习/冲刺的答案写入提取为共享 `submitAnswer`，判分、首答、辅助、原单元/训练组、幂等回执语义保持；新增 `source=pk` 与可选PK投影，不修改任何持久格式。
- 初始题目不返回目标wordId、答案、参考解释或剩余词列表。帮助、伪造next、教材页和冲刺切阶段请求在PK中由服务端拒绝。
- 答对与推进在一次请求完成；同requestId重试返回原快照，不重复加分或新建作答。同ID改body拒绝。
- 每局有递增revision；浏览器拒绝旧回包覆盖新题。服务器已提交但回包丢失时保留输入，以同编号重试；不在失败时伪报成功或让用户无意改写同一次答案。
- 首答错误再订正可获得比赛分，但回顾仍显示首答错误；没有把比赛分或“已结束”作为学习币/无辅助独立掌握。
- 复核同时修正本次回顾的统计：听读音后答对不计入“无辅助首答正确”，已用三尺寸真实浏览器覆盖；不把音频辅助漏掉。
- 全部在原匿名RAM模式，没有数据库、localStorage或sessionStorage，不读取私有词包、原浏览器记录或真实学习数据。

## 页面与视觉核对

沿用学习家园已有深青/浅青/绿色/黄色与原字体，不另造主题。准备页说明规则；开局后缩短页首，五个节点表示当前词的位置，计时、图、题意与输入相邻。截图复核后压缩了过长的开场说明和模型边距；1280×960强制检查输入框位于首屏，390/768/1280无横向溢出。页面遵循减少动态效果设置，支持Enter提交；过程不加自查勾选或弹窗确认。

源图只使用对应原卡已核验图，没有图片的词不生成替代图片。家庭素材截图留在被忽略的本地证据；Git仅归档合成图片。
