## 本批行为

英语成为家园内的独立学习空间 `/subjects/english`，共享侧边栏、抽屉和学科切换。教材按4册/单元/A-B组选择；Movers、KET、PET按原序分组。词卡与练习分开：看图/释义/例句/主动发音，随后补空、完整拼写、错误订正、教材页练习或本次错词回顾。

原正式词库合计6631张，665组，128页教材练习/1275答案槽。固定来源与完整模块状态见 [台账](MODULE-MATRIX.md)。原来源1863张图，其中1861张被原课程引用；另2张Book3 Unit7阅读图保留来源台账待核对，没有猜测挂接。

生词包只处理用户主动选择的V1公开格式文件：预览核对/选词后，在本页内存里练习；拒绝外链和SVG，校验图片真实可解码与尺寸，断网也可训练。测试只用合成包，未读取Kevin已有私人包。

## 自查后修正

1. LAN HTTP不支持浏览器randomUUID/subtle：改用getRandomValues构造UUID与纯SHA-256，测试禁用两个安全上下文接口后仍完成练习和本地词包。
2. 末题先显示结果再请求统计存在断网空统计：末题确认原子返回完整本次结果。
3. 历史幂等回执引用可变数组：保存独立深拷贝；重试旧汇总不会混入后来作答。
4. 网络结果不确定时不能随意换答案覆盖待重试请求：保留请求编号和原输入，提供重试；首答始终由服务先保存。
5. 题目ID和图片原文件名含词形可能泄题：练习随机taskId/内容哈希图片URL/中性alt，公开练习不发送词形、拼写变体或标准答案；学习词卡则有意显示单词。听读音和看参考需主动操作并留痕。
6. 错误同义词不误判目标拼写；参考后正确只能记订正，不能冒充第一遍答对。
7. 核对原V1公开词包的两种图片写法：dataUrl与mimeType/base64均兼容，source-only标题也能导入；未读取真实包验证。
8. 英语导航抽屉不出现数学路径；切换学科取消系统发音；错词请求失败给出重试提示，避免假装没有错词。
