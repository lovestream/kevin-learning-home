## 上线范围

已有家庭来源包仅用于已授权的家庭LAN范围，`publicationApproved=false`。默认公共镜像没有该包，显示明确装载状态。专用NAS叠层工具仅接受已通过CI且尚未对外发布的候选镜像，在其上加入固定来源内容包；先离线镜像探针，再用原发布工具切换同一端口并保留旧版。它不能改正在运行的容器、挂真实学习卷、放宽认证或修改证书。

最终NAS实际运行SHA与CI结论在本批交付报告填写，不能用“本地可用”替代“已部署”。
