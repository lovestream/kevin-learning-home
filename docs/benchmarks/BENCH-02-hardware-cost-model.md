# BENCH-02 硬件与长期成本参数模型

此表为可替换的预算假设，非市场报价、当前电价或购买建议；用户已有NAS成本是沉没成本，**增量成本和全系统更换成本分开**。没读取任何财务数据。价格跨十年会变化，所有固定价格十年乘法仅敏感性计算。

## 参数与公式（人民币）

假定电价0.60元/kWh，mini计算端平均10W，NAS全系统平均30W，NAS应用增量5W。年电费 `W/1000×8760×电价`：10W为52.56元、30W为157.68元、增量5W为26.28元。这不是实测功率；更换为15–45W和0.5–1元可自行重算。家庭宽带现有费用不当作免费无限上行，公网媒体体验需另测。

假设mini主机/SSD2000元、五年换一次；替换NAS主机4500元；每12TB盘1500元；UPS1000元且五年维护/更换一次。只有用于模型，不声称任何当前具体SKU价格。RAID5四盘12TB约36TB十进制逻辑容量，扣文件系统/快照后更少；镜像/RAID是冗余，不是异地备份。10TB在线＋10TB本地独立备份＋10TB异地副本意味着至少30TB逻辑副本，还需冗余/可用空间/增长余量；不能用一块10TB盘承诺十年安全。

维护时间单列：12–24小时/年，若按100元/小时计，十年12000–24000元；若用户自行维护不计现金支出也仍占时间。Cloudflare也需账户安全、监控、算法/依赖升级、备份恢复，模型6–12小时/年，不是免运维。未统计本次原型开发成本。

简例：mini计算十年设备两次4000＋电费525.60＋维护12000–24000＝16525.60–28525.60元，**不含**盘、UPS、NAS、宽带、异地存储、税费。已有NAS直接计算不能以0硬件成本抹去更换风险。固定功率/价格仅模型。

## 媒体容量与对象数量

假定平均对象10MB：10/100/1000/10000GB约1000/10000/100000/1000000对象；总容量不是下载请求数，备份次数、家庭上行、hash清单和恢复扫描时间另计。实际素材尺寸分布未导入。热DB本地SSD、媒体对象和冷档案各自扩容，不把对象当BLOB塞入学习DB或全部打包进app。

10TB通过20Mbps家庭上行传一次，理想下限 `10×10^12×8 / (20×10^6)` 秒≈46.3天；100Mbps约9.3天。是无协议开销/不限速的理论模型，不能据此承诺恢复时间；增量备份与本地物理恢复路线必须验证。失去NAS/路由/家庭电源时，异地副本和独立计算决定是否仍可用。

NAS采购成本不与USD云账单直接相加。需要比较时设置自选汇率（例如模型7.2元/USD，非当前汇率声明）；同样为云账号/域名/对象操作/备份/维护单列，详见共享横向报告的Cloudflare成本表。10TB两份R2副本的当期模型支出远高于家庭小量，不能由“访问少”推导永久免费。
