# 家园首页与长期导航设计

2026-11-05，依据用户对顶部标签式切换与首页的反馈实施。记录底座的未完成实现保存在 `codex/explore-02-records@af7c92f`，本轮不携带其数据库、媒体或认证变更。

## 结构

家园首页 `/` → 学习空间 `/subjects/math`、`/explore` → 学科内部的教材／单元／课堂。数学的课本、侦探、思维训练和复习仍归数学。跨空间通过稳定的全局导航与首页目录完成；顶部不随课程数量增加标签。

首页承担选择方向和寻找内容，不展示虚构的学习进度、连续天数、积分或“继续上次”。现 NAS 仍为匿名内存体验。英语与成长清楚标为准备中，不能用空链接冒充可用。

## 视觉计划

- 底色薄荷纸 `#EDF7F5`，正文深青 `#173D43`，侧栏 `#103E43`，行动色 `#167D7F`，纸黄色 `#F6C848`，探索点缀 `#F47759`。
- 沿用中文系统字体 PingFang SC / Noto Sans CJK SC；主标题 36–52px，区块标题 24–28px，正文 17px。左对齐，中文短行；不加外部字体请求。
- 桌面：稳定的家园侧栏；顶栏为品牌、当前位置和导航按钮；大标题与可互动书桌并置；下接数学书房、探索空间和教材书架。
- 手机：单列入口，标题在插图之前；统一抽屉导航，不横向滚动学科标签；输入框与关键按钮至少 44px。

```text
家园侧栏 | 品牌 / 当前位置                       学习导航
         | 你好，今天想发现什么？       纸盒、书和便签的小书桌
         | 找课程、知识点或学习空间 [____________________]
         | 数学书房（教材与多种学法） | 探索空间（问题到创作）
         | 我的教材书架：上册 / 下册 / 基础衔接
         | 换一种方法：侦探 / 思维卡 / 方法工具箱
         | 准备中的英语空间与成长空间
```

复核：不采用同尺寸四张功能卡或指标看板。数学以书架组织，探索以开放的问题与笔记组织；插画可点选观察方向，服务于学习主题。新学科通过空间注册表进入目录；导航仅固定少数常用入口，30 个合成空间的扩展测试保证顶栏结构不随之增长。

## 验收

五视口实际前后端、首页到教材到课堂及精确返回、跨空间导航与浏览器前进后退；搜索真实 70 课目录，空态和不可用入口准确；抽屉 Escape 回焦、键盘可达、无横向溢出。保留数学与探索全部回归。只在完整 CI 通过后通过既有受控发布更新 NAS38444，并验证回退与原服务不变。
