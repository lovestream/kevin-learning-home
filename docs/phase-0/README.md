## 核心发现

1. **数学有两个不同的有效基线。** GitHub `main` 是任务书的 `1e8199d`；本地与远端 `audit-fixes-20261002` 分支是 `8e91154`，比 main 多 11 个提交。后者已有家长 PIN、思维卡批阅、首答/自查证据及关键浏览器 CI。不能从旧 main 迁移后宣布这些能力已保留。本轮不修改或合并旧仓库。
2. **数学已有持久化和事务，英语已有 V2 事件模型与本机冲突保护。** 英语缺的是服务器可信判分和跨设备持久化，不是完全没有数据模型。保留两科现有判分、复习算法和课程，逐步加 Adapter。
3. **数学宠物 XP 是伙伴成长，不是全局学习 XP。** 英语金币初始值为 20，奖励账本只保留最近 500 条，无法据账本重建全部金币。两科历史不能直接相加或重放奖励。本轮只记录来源钱包，不建立中央余额。
4. **当前 NAS 不是可直接认定兼容 Node 24 的环境。** DS918+ / DSM 7.1.1 / Linux 4.4.180+；Node 24 的官方 glibc Linux x64 支持表要求内核至少 4.18。Docker 不更换宿主内核。此项需要后续兼容探针及明确部署路径决策。
5. **真实备份未完成。** 本地 `math-learning/data/progress.sqlite` 不存在；真正使用的数学 `--data-dir` 尚未定位，真正使用的浏览器 WordQuest 导出尚未提供。本轮没有读取孩子的记录，不能给出真实记录数量、完整性结论或“已迁入”结论。
